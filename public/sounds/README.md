# Sound Effects

This directory contains sound effects for the quiz app.

## Required Files

Place the following MP3 files in this directory:

1. **correct.mp3** - Plays when user selects correct answer
   - Suggested: Short positive sound (ding, chime, success tone)
   - Duration: 0.5-1 second
   - Example sources: freesound.org, zapsplat.com

2. **wrong.mp3** - Plays when user selects wrong answer
   - Suggested: Short negative sound (buzz, error tone)
   - Duration: 0.5-1 second

3. **complete.mp3** - Plays when quiz is completed
   - Suggested: Celebration sound (fanfare, applause, victory)
   - Duration: 1-3 seconds

## Free Sound Resources

- [Freesound.org](https://freesound.org/) - Free sound effects library
- [Zapsplat](https://www.zapsplat.com/) - Free sound effects
- [Mixkit](https://mixkit.co/free-sound-effects/) - Free sound effects

## Creating Simple Sounds

If you don't have sound files, you can:
1. Use online tone generators to create simple beep sounds
2. Record your own sounds
3. Use text-to-speech tools
4. Download from free sound libraries (with proper licensing)

## Note

The app will work without sound files - it will simply fail silently if files are missing.
